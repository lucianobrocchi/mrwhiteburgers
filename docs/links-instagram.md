# Links de Instagram — Mr. White Burgers

Cada link lleva "etiquetas" (utm) para que Google Analytics sepa **de dónde vino cada visita y cada pedido**.
Sin etiqueta, Instagram aparece como "directo" y no se puede saber qué publicación funciona.

| Dónde va | Link |
|---|---|
| **Bio del perfil** (@mr.whiteburgers) | `https://mrwhiteburgers.com.ar/?utm_source=instagram&utm_medium=bio&utm_campaign=mrwhite` |
| **Historias** (sticker de link) | `https://mrwhiteburgers.com.ar/?utm_source=instagram&utm_medium=historias&utm_campaign=mrwhite` |
| **Anuncios pagos** | `https://mrwhiteburgers.com.ar/?utm_source=instagram&utm_medium=paid_social&utm_campaign=NOMBRE-DEL-ANUNCIO` |

Cómo se lee en Analytics (Informes → Adquisición → Adquisición de tráfico):
- `instagram / bio` y `instagram / historias` aparecen dentro de **Organic Social**.
- `instagram / paid_social` aparece como **Paid Social** (anuncios).
- Cambiá `NOMBRE-DEL-ANUNCIO` por algo corto sin espacios (ej. `promo-2x1`, `chesse-joa`): así ves cuál anuncio trae pedidos.

Reglas para armar otros links: siempre en minúsculas, sin espacios ni tildes, y `utm_source=instagram` igual en todos.
